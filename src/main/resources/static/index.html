Социометрическая матрица

Строка — кто выбирает, столбец — кого выбирают. Щелчок по клетке переключает выбор. Подсвечены взаимные пары.

взаимный выбор односторонний выбор диагональ (себя выбрать нельзя)

Загрузка результатов из файла

Поддерживаются CSV и XLSX в двух форматах.

Длинный формат

По строке один выбор. Колонки type, respondent, target, rank, где type — SYMPATHY или ANTIPATHY, rank — место в предпочтении (необязательно).

type,respondent,target,rank
SYMPATHY,1,2,1
SYMPATHY,1,3,2
ANTIPATHY,1,12,1

Широкий формат (сама матрица)

Первая колонка — код выбирающего, остальные — коды участников. Значение 1 — выбрал, 0 — нет, число больше 1 трактуется как ранг.

;1;2;3
1;0;1;1
2;1;0;1
3;1;1;0
